# Wallet Development Skills

区块链钱包开发相关 Agent Skills 集合。

## Skills

1. [Wallet Security Review](./wallet-security-review/SKILL.md) — 区块链钱包 / Web3 前端项目安全代码审查。覆盖密钥与敏感数据、数值精度与大数运算、交易与风控、dapp 授权与注入防护、供应链依赖、日志与信息泄露六大类风险，输出 P0/P1/P2 分级安全审查报告
2. [Wallet UX Review](./wallet-ux-review/SKILL.md) — 区块链钱包 / Web3 前端项目用户体验优化审查。覆盖金额与数据展示、交易流程体验、状态与稳定性、隐私与安全体验、错误处理与恢复、网络与链切换、引导与教育、可读性与本地化八大类，输出 P0/P1/P2 分级体验优化报告

## Install

```sh
npx skills add vanishcode/wallet-development-skills
```
