# Wallet Development Skills

区块链钱包开发相关 Agent Skills 集合。

## Skills

1. [Wallet Security Review](./wallet-security-review/SKILL.md) — 区块链钱包 / Web3 前端项目安全代码审查。当代码变更涉及钱包、助记词、私钥、签名、授权（approve）、gas、nonce、dapp 交互、MPC/多签、EIP-4337、EIP-7702 等逻辑时，对 git diff 进行安全扫描，覆盖八大类风险（密钥与敏感数据、数值精度与大数运算、交易与风控、dapp 授权与注入防护、供应链依赖、日志与信息泄露、状态持久化、UI 展示一致性），并输出 P0/P1/P2 分级安全审查报告
